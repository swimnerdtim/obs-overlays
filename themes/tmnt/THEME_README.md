# TMNT Theme for Swimnerd Live Overlays

**Cowabunga!** This is a CSS theme file for existing Swimnerd Live overlay templates.

## How to Use

### Step 1: Add to Your Overlay HTML

Open your overlay template files (`HeaderOverlay.html`, `LaneOverlay.html`, `TimerOverlay.html`) and add this line to the `<head>` section:

```html
<link href="themes/tmnt/tmnt-theme.css" rel="stylesheet">
```

### Step 2: That's It!

The TMNT theme will automatically apply to your existing overlays. No other changes needed.

## Theme Features

**TMNT Color Palette:**
- 🐢 Turtle Green (`#4CAF50`)
- 🍕 Pizza Orange/Red (`#FF6B35` / `#E52521`)
- 💛 Pizza Yellow (`#FFD93D`)
- 🌃 Sewer Dark Green (`#0a3d0a`)

**Turtle Colors Rotate Through Lanes:**
- Lane 1, 5: Leonardo Blue (`#2196F3`)
- Lane 2, 6: Raphael Red (`#F44336`)
- Lane 3, 7: Donatello Purple (`#9C27B0`)
- Lane 4, 8: Michelangelo Orange (`#FF9800`)

**Animations:**
- **Sewer Slide-In** - Lanes slide in from left (like coming out of a sewer pipe)
- **Pizza Bounce** - Place indicators bounce when appearing
- **Pizza Drop/Rise** - Split times drop in like pizza boxes
- **Turtle Power!** - First place gets pulsing golden glow
- **Pizza Spin** - Timer decoration rotates

**Styling:**
- Bold Impact font (comic book style)
- All caps text (TMNT attitude!)
- Thick black outlines on text (comic book shadows)
- Sewer pipe gradients for event name
- Pizza box gradients for headers
