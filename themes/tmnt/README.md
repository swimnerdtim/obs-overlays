# TMNT Scoreboard Theme - Turtle Power! 🐢🍕

Cowabunga! The Teenage Mutant Ninja Turtles come to your swim meet.

## Features

- **Sewer aesthetic** - Dark green gradient background with brick texture overlay
- **Pizza box header** - Orange/red gradient (because turtles love pizza!)
- **Turtle color borders** - Each lane rotates through Leonardo (blue), Raphael (red), Donatello (purple), and Michelangelo (orange)
- **Comic book style** - Bold Impact font with thick black text shadows
- **Pizza slice decorations** - Floating 🍕 emojis with rotation animation
- **First place shell** - Golden yellow highlight with pulsing "Turtle Power" glow
- **Sewer grate footer** - Dark metallic finish

## Animations (Inspired by Luke's Mario Theme)

- **Sewer Slide-In** - Lanes slide in from left with bounce (staggered by 80ms per lane)
- **Pizza Bounce** - Place numbers bounce up like jumping turtles
- **Turtle Power Glow** - First place pulsates with golden energy (infinite loop)
- **Pizza Box Drop** - Header drops from above with satisfying bounce
- **Pizza Float** - Background pizza slices float and rotate gently
- **First place time** - Bounces continuously to celebrate the win!
- **TURTLE CHASE!** 🐢🥷👾 - All 4 turtles (with colored glows!) run across the screen chased by Shredder and Krang
  - Manhole cover spins in at left
  - **Retro 8-bit sprites** generated with AI (authentic arcade game aesthetic!)
  - Leonardo (blue glow), Raphael (red), Donatello (purple), Michelangelo (orange)
  - Shredder and Krang chase them with evil glows
  - 8-second run across the screen
  - Triggers 1.5 seconds after lanes load
  - Each turtle: 80x80px, villains: 85x85px
  - Pixelated rendering for authentic retro look

## Color Palette

**Turtle Colors (lane borders):**
- Leonardo: `#2196F3` (blue)
- Raphael: `#F44336` (red)
- Donatello: `#9C27B0` (purple)
- Michelangelo: `#FF9800` (orange)

**Core Colors:**
- Background: Dark green sewer (`#0a3d0a`)
- Lanes: Turtle shell green (`#4CAF50`)
- Text: White with black outlines (comic book style)
- Accents: Pizza yellow (`#FFEB3B`)
- First place: Golden shell (`#FFC107`)

## Typography

- Font: **Impact** (bold, uppercase, comic book style)
- All text has thick black outlines for readability
- Uppercase swimmer names for maximum impact

## Vibe

80s/90s arcade game meets New York City sewers. Perfect for teams that want high-energy, nostalgic, pizza-loving turtle power! 🐢⚡
