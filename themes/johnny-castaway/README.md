# Johnny Castaway Scoreboard Theme

The classic 90s screensaver meets modern swim meet scoreboard.

## Features

- **Authentic Johnny Castaway** - Embeds the real JavaScript port (https://castaway.xesf.net)
- **Retro terminal aesthetic** - Green CRT-style text with glow effects
- **Scanline overlay** - Subtle CRT screen effect
- **8-lane support** - Full race results with splits and final times
- **First place highlight** - Gold glow for winners

## What You See

**Top (300px):** Real Johnny Castaway animation
- Fishing, jogging, building shelter, random activities
- True to the original 1992 screensaver
- Random scene selection (not scripted story)

**Middle:** Race results with classic terminal styling
- Green monospace font (Courier New)
- Cyan lane numbers, yellow clock, magenta splits
- CRT glow effects on all text

**Bottom:** Event info footer
- Event number, heat, lengths, pool record

## Color Palette

- Background: `#000000` (black)
- Primary text: `#00FF00` (terminal green)
- Lane numbers: `#00FFFF` (cyan)
- Clock: `#FFFF00` (yellow)
- Splits: `#FF00FF` (magenta)
- First place: `#FFFF00` (yellow glow)

## Why This Works

Instead of creating a custom story with static images, we embed the **real** Johnny Castaway that people remember from the 90s. The randomness IS the magic - you never know what Johnny's doing when you look up at the scoreboard.

Perfect for teams that want nostalgia + functionality.
