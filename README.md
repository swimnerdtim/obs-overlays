# Swimnerd Live - Digital Scoreboard Themes

Beautiful, production-ready themes for Swimnerd Live.

## 🎨 Available Themes

- **Barbie** - Hot pink paradise with Castaway-style story animations ⭐ **LIVE NOW**
- **TMNT** - Teenage Mutant Ninja Turtles sewer power! (80s arcade style) ⭐ **LIVE NOW**

## 🏊 Built For Swimnerd Live

Designed for competitive swim meets using [Swimnerd Live](https://swimnerd.com) scoreboard software.

### What Each Scoreboard Shows:
- Event number and name
- Heat info (3 of 4)
- 8 lanes with swimmer names and teams
- Split times + final times
- Live race clock
- Place updates on finish
- Pool records

## 📺 Two Ways To Use

### 1. Full-Screen Scoreboard (Recommended!)
Perfect for TVs around the pool deck. Replaces satellite displays.

- Open `themes/barbie/scoreboard.html` on any TV browser
- Or cast it from your laptop
- Connects to Swimnerd Live via BroadcastChannel API

### 2. OBS Overlays (For Livestreams)
Overlay event info and results on your livestream.

- `event_header.html` - Event name and heat
- `lane_results.html` - Live results
