# Swimnerd Live - OBS Overlay Themes

Beautiful, production-ready themes for Swimnerd Live scoreboard software.

## 🎨 Available Themes

- **Barbie** - Pink paradise with gradient overlays and playful vibes
- More themes coming soon! (Olympics, Ocean, Neon, Christmas)

## 🏊 Built For Swimnerd Live

These themes are designed for competitive swim meets using [Swimnerd Live](https://swimnerd.com) scoreboard software.

### Compatible With:
- Event headers
- Lane results
- Heat/Final displays
- Timer overlays
- Full meet scoreboards

## 📖 How To Use

1. Download the theme folder you want
2. In OBS, add a Browser Source
3. Point it to the theme's HTML file
4. Configure width/height based on theme documentation
5. Connect to Swimnerd Live via BroadcastChannel API
